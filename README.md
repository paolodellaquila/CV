# Francesco Paolo Dellaquila — Portfolio

Personal portfolio site (vanilla HTML / CSS / JS).

**Live:** https://paolodellaquila.github.io/CV/

## Stack

- Semantic HTML5
- Modern CSS (custom properties, Grid, Flexbox, mobile-first breakpoints)
- Vanilla JavaScript (menu, cookies GDPR, contact reveal, form validation)

## Structure

```
index.html
cookie-policy.html
privacy-policy.html
style.css
script.js
robots.txt
sitemap.xml
assets/
  images/
  icons/
  fonts/
  cv.pdf
```

## Local preview

Open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.
